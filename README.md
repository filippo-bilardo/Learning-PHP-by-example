# Learning PHP by Example

Corso pratico per imparare lo sviluppo backend con PHP 8.3: dal linguaggio e
dalla programmazione a oggetti fino ad API, database, sicurezza e deployment.

- [Corso PHP](docs/README.md)
- [Capitolo 2: Ambiente di sviluppo](docs/02-Ambiente_di_sviluppo/README.md)
- [Capitolo 3: Sintassi e costrutti di base](docs/03-Sintassi_e_costrutti_di_base/README.md)
- [Ambiente Codespaces](.devcontainer/README.md)

Gli esempi e la pagina iniziale sono in `www`. In Codespaces il server parte
automaticamente sulla porta 8000. Per avviarlo in locale dalla cartella del progetto:

```bash
php -S 0.0.0.0:8000 -t www
```

Apri `http://localhost:8000` per accedere al corso, a **Hello PHP** e al form
di **Pagina riservata** (utente `admin`, password `php123`).
