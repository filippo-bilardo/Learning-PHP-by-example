# PHP by Example

## Introduzione

Questo corso propone un percorso progressivo per costruire applicazioni web
con PHP 8.3. Ogni capitolo contiene obiettivi, guide, esempi ed esercizi.
Il progetto finale consigliato è una API per la gestione di attività con
utenti autenticati.

## Requisiti

- PHP 8.3 o successivo con estensioni `pdo_mysql`, `mbstring` e `openssl`
- Composer 2
- Un database MySQL 8 o MariaDB
- Un editor con supporto PHP, ad esempio Visual Studio Code

Per i primi capitoli bastano PHP e un browser; Composer, database ed estensioni
specifiche vengono utilizzati nelle attività che li richiedono.

## Capitoli disponibili

1. [Introduzione a PHP](01-Introduzione/README.md): linguaggio, modello client-server, HTTP, pagine statiche e dinamiche, sviluppo server-side.
2. [Ambiente di sviluppo](02-Ambiente_di_sviluppo/README.md): Web4Student, php.ini, Apache, Nginx, XAMPP, GitHub Codespaces e altre soluzioni online.
3. [Sintassi e costrutti di base](03-Sintassi_e_costrutti_di_base/README.md): variabili, tipi, operatori, strutture condizionali e cicli, con guide, esempi ed esercizi.
