# PHP by Example

## Introduzione

Questo corso propone 20 esercitazioni progressive per costruire applicazioni
web robuste con PHP 8.3. Ogni modulo contiene obiettivi, concetti essenziali,
un esempio da eseguire ed esercizi. Il progetto finale consigliato è una API
per la gestione di attività con utenti autenticati.

## Requisiti

- PHP 8.3 o successivo con estensioni `pdo_mysql`, `mbstring` e `openssl`
- Composer 2
- Un database MySQL 8 o MariaDB
- Un editor con supporto PHP, ad esempio Visual Studio Code
