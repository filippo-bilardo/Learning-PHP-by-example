## Esecuzione dal terminale

Dalla cartella principale del progetto, per esempio:

```bash
php www/03-sintassi-e-costrutti-di-base/esempi/04_Cicli_Iterazioni/01_Cicli_Base.php
```

Prima prevedi l'output, poi esegui e confronta. Le funzioni introdotte negli
esempi servono a illustrare scope e callback; avranno un capitolo dedicato.
